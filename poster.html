SportMind

Ten NBA seasons sit in a graph, a vector store, and a small set of models, and you ask in English.

Neo4jRAGReact

Question

  • What did this player do, how does this team relate, and what is a fair win probability from box scores alone?

Method

  • 2013-14 through 2022-23 ingested into Neo4j and Weaviate.
  • A FastAPI backend streams chat. The React app is the front door.
  • Win probability is a classifier. Player stats use 658 EWMA forecast models.

Evidence

~1,400players

What the result actually says

  • Ten seasons, 2013-14 through 2022-23: about 1,400 players, about 12,800 games, and 6,246 document chunks in the vector store.
  • Win probability holds out 2022-23. Test AUC is 0.626, accuracy 61.0%, calibrated Brier score 0.235. Cross-validation AUC was 0.675.
  • Player forecasts are 658 EWMA models, 94 players by 7 stats. On the 2022-23 holdout, points MAE is 5.24 and assists MAE is 1.61.

What it does not show

  • Box scores without in-game data sit near the ceiling people report for this feature set, about 58–65% accuracy. 61% is inside that band, not above it.
  • Neo4j and Weaviate have to be running already. The start script only opens the API and the React app.

Beside the other attempts

  • The win model keeps rolling form, rest, head-to-head, and venue. Thirty-two candidates were pruned to that set.
  • Isotonic calibration is applied to the raw win probabilities. The Brier score is the calibrated one.

Stack

Neo4j, Weaviate, FastAPI, React. Chat streams over a websocket. Win model is XGBoost. Forecasts are per-player EWMA.
